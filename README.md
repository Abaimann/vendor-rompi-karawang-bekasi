## ✨ Fitur Aplikasi Web

1. **Desain Tajam Kotak-Kotak (Neo-Brutalist Industrial):**
   * Sudut tegas *zero border-radius* (`0px`), garis batas hitam tebal `2.5px`, dan bayangan *offset* keras `4px 4px 0px #000`.
   * Latar berpola grid cetak biru 28px dengan palet kontras tinggi: *Safety Yellow* (`#FACC15`), *Electric Cyan* (`#38BDF8`), dan *Hazard Orange* (`#FB923C`).
2. **Animasi & Interaksi Responsif:**
   * Animasi kemunculan kartu bertahap (*stagger slide-up*).
   * Efek tekan taktil saat tombol diklik (turun `2px 2px` dengan bayangan rata).
   * Efek melayang (*hover lift*) saat kursor diarahkan ke kartu.
   * Indikator denyut (*pulse badge*) penanda direktori aktif.
3. **Sistem Filter & Live Search:**
   * **Pencarian Instan:** Mencocokkan nama vendor, wilayah, spesialisasi bahan (drill, taslan, ripstop, mesh), dan deskripsi secara real-time.
   * **Filter Wilayah:** Karawang (35), Cikarang (30), Tambun-Cibitung (15), Kota Bekasi (20).
   * **Filter Kategori Produk:** ⚡ Safety K3, 🛠 Tactical / Saku, 🏭 Wearpack Pabrik, 🏍 Taslan / Bikers, 👔 Kantor & Dinas, 🦺 Jaring Mesh.
   * Tombol *Reset Filter* instan.
4. **Dioptimalkan untuk Mobile (Mobile-First):**
   * *Sticky navigation bar* di bagian atas layar HP.
   * Tombol horizontal scrollable chips yang ramah sentuhan jempol.
   * Tombol aksi ganda per vendor: **🌐 Tautan Web/Katalog** & **📍 Navigasi Peta Google Maps**.
   * Tombol melayang *smooth-scroll* **"▲ KE ATAS"**.
